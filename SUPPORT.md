# Support

## Where to ask

- **Using the platform, or stuck on an activity** — open an issue at
  <https://github.com/myzticalbabe/wasm-education/issues/new>. Say what you tried and
  paste the full output you got.
- **A bug** — use the bug report form. A minimal reproduction (which page, which module,
  which click path) gets a fix far faster than a description of symptoms.
- **A security problem** — do not open a public issue; follow [SECURITY.md](SECURITY.md).
  The threat model is small by design: the kids track collects nothing, has no accounts
  and makes no network requests after load.
- **An accessibility barrier** — see [ACCESSIBILITY.md](ACCESSIBILITY.md) for what is
  already known, then open an issue.
- **Running this in a classroom, club or troop** — read [STEM.md](STEM.md) first; it has
  the session plan and the vocabulary list. Timed plans, differentiation and the
  assessment rubric are in [`docs/FACILITATOR-GUIDE.md`](docs/FACILITATOR-GUIDE.md).
- **A facilitator report** — the most valuable contribution you can make. Use the
  [facilitator report form](.github/ISSUE_TEMPLATE/facilitator_report.yml) after a real
  session: what worked, what confused learners, what you had to explain twice.

## What to include

1. What you expected to happen.
2. What happened instead — the exact text, not a paraphrase.
3. The page and click path that produces it, plus your browser and operating system.
4. For build problems: `rustc --version`, `tinygo version`, `node -v`, and the full
   command output.

## What this project is not

It is not a commercial product and there is no paid support tier. Maintainers answer
when they can. A question that goes unanswered for a week is not a rejection — add
detail and ask again rather than giving up quietly.

## For learners

If you are a student using this platform for a class or a club project, you are welcome
to ask questions here. Nobody will be told that your question was too basic, and asking
is not evidence that you are behind.
