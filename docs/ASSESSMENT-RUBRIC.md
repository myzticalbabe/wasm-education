# Assessment Rubric — Brain Explorer Kids

The platform has badges, XP and a trophy case. None of those are assessment: they
measure clicks. This rubric measures the thing that matters — whether a learner can
**explain what they saw**.

Use it three ways:

- **Formative**, mid-session, by you while circulating.
- **Self-check**, at the end, one copy per pair.
- **Summative**, if you are counting this toward a unit, by collecting the written
  claim and the annotated screenshot.

Do not grade the badges. Do not grade speed.

---

## The one thing being assessed

Every module ends with a claim of the form:

> *"____ happens because ____."*

That structure is used deliberately. "Because" is the word that separates a
description from an explanation, and it is the word that NGSS SEP 6 (Constructing
Explanations) and CSTA 1B-DA-07 both turn on.

## Rubric (4 levels, 3 criteria)

| | **4 — Explains** | **3 — Connects** | **2 — Describes** | **1 — Names** |
|---|---|---|---|---|
| **Claim** | States a claim and supports it with a specific observation from the run | States a claim and points at the observation that supports it | States what happened, with no claim about why | Names the feature or button without saying what happened |
| **Mechanism** | Uses the module's mechanism correctly *and* says what would change it | Uses the mechanism correctly | Uses the vocabulary but mixes up the direction of cause | Uses the vocabulary as a label only |
| **Revision** | Changes one variable, predicts the effect, and reconciles a surprise | Changes one variable and reports the effect | Changes a variable without predicting | Does not change a variable |

### Worked examples

**Word Web, level 4:** *"Attention lights up because it is wired to Working Memory,
and when I activated Working Memory the spread reached it in one step. When I
activated Schema instead, Attention stayed dim — so it is the direct link that
matters, not just being in the web."*

**Word Web, level 2:** *"Everything lit up in green and then faded."*

**Neuron Lab, level 3:** *"The neurons fire more when I raise the input current,
and they fire in a pattern instead of all together."*

**Thought Paths, level 4:** *"The shortest path went through Attention but the
cheapest path went the long way round. Shortest is not the same as best — it
depends what you are paying for."*

**Brain Power Meter, level 4:** *"Extraneous load is the part I can remove. When I
turned the time pressure down, the bars emptied even though the task was the same
size — so the pressure was adding load that wasn't the task."*

## Per-module evidence to look for

| Module | Evidence of understanding | Common misconception to catch |
|---|---|---|
| Word Web | Predicts *which* neighbours activate before clicking; distinguishes "connected" from "close" | "Everything is connected to everything" — probe for direction and strength |
| Neuron Lab | Separates membrane behaviour from network behaviour; reads a raster plot | "A bigger spike means a stronger thought" — amplitude is roughly constant; the code is in timing |
| Thought Paths | Names the trade-off between shortest and cheapest; explains why the visited set prevents revisiting | "The computer just knows the answer" — ask *how* it knows |
| Brain Power Meter | Reassigns a demand to the right load category | "All difficulty is bad" — intrinsic load is the learning |

## Self-check card (print, one per pair)

```
Our claim:  ______________________________ happens because ______________________________

The evidence we saw: ______________________________________________________________

One thing we changed, and what happened: ___________________________________________

One thing that surprised us: _______________________________________________________
```

## Programme-level reporting

If you need a number for a grant report or a school, report the **percentage of
learners reaching level 3 or above on "Mechanism"**, not the mean XP. XP measures
persistence; mechanism measures learning. Persistence is worth reporting too, but
as a separate engagement figure — and state plainly that it is engagement, not
achievement.
